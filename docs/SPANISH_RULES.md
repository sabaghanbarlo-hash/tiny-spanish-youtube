# Tiny Spanish: language rules

Default variety: neutral Latin American Spanish. Level order A1, A2, B1, B2. Start at A1.

1. Every Spanish sentence must be grammatically correct, with accents, ñ, ¿? and ¡! (opening and closing marks).
2. English translations are natural, never word-for-word ("¿Cómo te llamas?" = "What's your name?").
3. No vosotros/vuestro/-áis/-éis forms. Use ustedes. Only a lesson explicitly about Spain may use vosotros (header `variety: spain`).
4. Use tú with friends and usted with strangers; when it matters, say which one in the grammar note.
5. Prefer Latin American vocabulary (the car = el carro/el coche, to take = tomar; mention a regional variant only when it saves a beginner from confusion).
6. At A1: present tense, ser/estar/tener/ir/gustar, no subjunctive. One new grammar idea per episode, 3-6 new words or phrases.
7. Reuse earlier vocabulary instead of piling up new words; each episode lists `vocab_new` and may recycle `vocab_review`.
8. Pronunciation lines use simple English respelling with stressed syllable in CAPS ("MOO-choh GOO-stoh"). Add them only where they help.
9. Never invent "natural" expressions. If unsure, use the plain correct form.
10. Spanish text is checked with `tools/validate_script.py` before rendering. A native or advanced reviewer should read the first ten episodes (the validator checks form, not meaning).
